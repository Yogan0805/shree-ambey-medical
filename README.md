# Shree Ambey Medical Stores

A simple medical store website built with Next.js and Tailwind CSS.

This website allows users to upload prescriptions, check medicine availability, and contact the store easily.  
Trusted medical store serving the community since 2000.

## Features
- Prescription upload
- Medicine availability check
- Login & Sign up pages
- Clean and responsive UI

## Tech Stack
- Next.js
- React
- Tailwind CSS
